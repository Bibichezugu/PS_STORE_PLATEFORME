# MASTER — Dossier central PS STORE

Ce dossier rassemble les trois documents de référence par domaine. Les fichiers sont séparés pour faciliter le travail de chaque fonction, tout en gardant ici une copie centralisée du référentiel.

## Documents

1. [Administration système hybride](01-ADMINISTRATEUR-SYSTEME.md) — Cloud, serveur physique, réseau, sécurité, sauvegardes, supervision et déploiement.
2. [Design UI/UX](02-DESIGN.md) — identité visuelle, parcours clients, écrans, composants et livrables designer.
3. [Main-d'œuvre et programmation](03-MAIN-DOEUVRE-PROGRAMMATION.md) — rôles, responsabilités, équipe, phases, sprints, qualité et livrables.

## Règle de gestion documentaire

- Chaque domaine conserve son document autonome.
- Toute modification importante doit être reportée dans la copie correspondante de ce dossier MASTER.
- En cas de divergence, vérifier la date/version et faire valider la version de référence par le responsable concerné.
- Les documents décrivent des spécifications et des propositions : ils ne prouvent pas qu'un achat, recrutement, déploiement ou test a été effectué.

## État du projet

Le dossier MASTER est un référentiel documentaire. Il ne remplace pas le code source applicatif, le backlog Scrum, les issues ou les preuves de tests.
